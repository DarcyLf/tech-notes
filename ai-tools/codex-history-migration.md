# 迁移 Codex 本地历史对话：从自定义 Model Provider 切换到 OpenAI

## 背景

此前我在 Codex 中使用自定义 model provider。切换到 ChatGPT 官方账号登录后，
发现部分历史对话虽然仍然能够在客户端中看到，但无法继续对话，并出现如下错误：

> Model provider `自定义model provider的名字` not found.

进一步检查后发现，旧会话使用的 provider 信息不仅存在于配置文件中，
还保存在 Codex 的本地历史数据中。
